# pipelog

Pipe timestamps and log durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/pipelog/

## Install / run

```bash
git clone https://github.com/theworker02/pipelog.git
cd pipelog
node src/cli.js
node --test
```
